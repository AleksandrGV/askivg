## 🌐 **Что нужно изменить при публикации сайта в интернет**

### 📋 **Локально работает, а в сети - нет? Вот что нужно исправить:**

## 🔧 **1. Главная проблема: PHP не работает на GitHub Pages**

**GitHub Pages поддерживает только статические файлы (HTML, CSS, JS). PHP не работает!**

### **Решение: Перенос на хостинг с поддержкой PHP**

#### **Вариант А: Бесплатный хостинг с PHP**
- **InfinityFree** (бесплатно, есть PHP + MySQL)
- **000webhost** (бесплатно)
- **AwardSpace** (бесплатно)
- **Heroku** (ограниченно бесплатно)
- **Railway** (есть бесплатный тариф)

#### **Вариант Б: Платный хостинг (рекомендуется)**
- **Beget** (от 200₽/мес)
- **Reg.ru** (от 150₽/мес)  
- **Timeweb** (от 200₽/мес)
- **Никогда не используйте GitHub Pages для PHP!**

## 🔧 **2. Что нужно изменить в коде для публикации:**

### **A. Файл `php/config.php`:**

```php
<?php
// Конфигурация базы данных - ИЗМЕНИТЕ НА ДАННЫЕ ХОСТИНГА
define('DB_HOST', 'localhost'); // На хостинге чаще всего localhost
define('DB_USER', 'your_username'); // Имя пользователя БД (выдаст хостинг)
define('DB_PASS', 'your_password'); // Пароль от БД (выдаст хостинг)
define('DB_NAME', 'your_database'); // Имя базы данных (создаете на хостинге)

function getDBConnection() {
    $conn = new mysqli(DB_HOST, DB_USER, DB_PASS, DB_NAME);
    
    if ($conn->connect_error) {
        return ['error' => 'Connection failed: ' . $conn->connect_error];
    }
    
    $conn->set_charset("utf8mb4");
    return $conn;
}
?>
```

### **B. Файл `js/script.js` - измените URL:**

```javascript
// Вместо относительных путей, укажите абсолютные или оставьте относительные
// Относительные пути РАБОТАЮТ на хостинге, если структура та же

// Было (работает):
url: 'php/add_comment.php',

// Если не работает, попробуйте:
url: '/php/add_comment.php',  // с ведущим слешем

// Или абсолютный путь:
url: 'https://your-domain.com/php/add_comment.php',
```

### **C. Создайте файл `.htaccess` (для Apache):**

```apache
# .htaccess - для правильной работы PHP на хостинге
AddDefaultCharset UTF-8

# Защита от просмотра папок
Options -Indexes

# Обработка ошибок
ErrorDocument 404 /404.html

# PHP настройки
php_value upload_max_filesize 10M
php_value post_max_size 10M
php_value max_execution_time 300
```

## 🔧 **3. Пошаговая инструкция для публикации:**

### **Шаг 1: Выберите хостинг**
Регистрируетесь на **Beget** или **Timeweb** (для России)

### **Шаг 2: Создайте базу данных**
```sql
-- Выполните на панели управления хостингом (phpMyAdmin)
CREATE DATABASE your_database_name;
USE your_database_name;

CREATE TABLE comments (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL,
    comment TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### **Шаг 3: Загрузите файлы**
```bash
# Через FTP (FileZilla) или файловый менеджер хостинга
/ (корень сайта)
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── php/
│   ├── config.php      # ← ИЗМЕНИТЬ ДАННЫЕ БД
│   ├── add_comment.php
│   └── get_comments.php
└── img/
    └── logotype.png
```

### **Шаг 4: Настройте права доступа**
```bash
# На хостинге установите права:
chmod 755 php/
chmod 644 php/*.php
chmod 755 css/ js/ img/
```

## 🔧 **4. Альтернативное решение (без PHP):**

### **Используйте Google Sheets как базу данных:**

```javascript
// script.js - альтернатива для GitHub Pages
// Используем Google Apps Script как бэкенд

const SCRIPT_URL = 'https://script.google.com/macros/s/your-script-id/exec';

function loadComments() {
    $.ajax({
        url: SCRIPT_URL + '?action=get',
        type: 'GET',
        success: function(response) {
            displayComments(JSON.parse(response));
        }
    });
}

function addComment(name, email, comment) {
    $.ajax({
        url: SCRIPT_URL,
        type: 'POST',
        data: { action: 'add', name: name, email: email, comment: comment },
        success: function(response) {
            loadComments(); // Обновить список
        }
    });
}
```

### **Или используйте Firebase (бесплатно):**

```javascript
// Firebase конфигурация
const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    authDomain: "your-project.firebaseapp.com",
    databaseURL: "https://your-project.firebaseio.com",
    projectId: "your-project",
};

firebase.initializeApp(firebaseConfig);
const db = firebase.firestore();

// Добавление комментария
db.collection("comments").add({
    name: name,
    email: email,
    comment: comment,
    timestamp: firebase.firestore.FieldValue.serverTimestamp()
});

// Загрузка комментариев
db.collection("comments")
    .orderBy("timestamp", "desc")
    .onSnapshot((snapshot) => {
        const comments = [];
        snapshot.forEach(doc => {
            comments.push(doc.data());
        });
        displayComments(comments);
    });
```

## 📋 **Чек-лист перед публикацией:**

- [ ] **Проверить PHP версию** - нужна 7.4 или выше
- [ ] **Проверить расширения MySQL** - mysqli должно быть включено
- [ ] **Изменить данные БД** в `config.php`
- [ ] **Создать базу данных** на хостинге
- [ ] **Импортировать SQL** таблицу
- [ ] **Проверить пути** - все ли файлы на месте
- [ ] **Проверить права** на запись (если нужно)
- [ ] **Протестировать** форму после загрузки

## 🎯 **Что НЕ нужно менять:**

✅ Пути в `index.html` - остаются относительными  
✅ CSS и JS файлы - остаются без изменений  
✅ Структуру папок - сохраните как есть  
✅ HTML разметку - не трогайте

## ⚠️ **Важное предупреждение:**

**GitHub Pages НЕ ПОДДЕРЖИВАЕТ PHP!**  
Если вы выложите PHP файлы на GitHub Pages, пользователи увидят:
- Исходный код PHP (что опасно!)
- Или ошибку 404
- Форма работать не будет

**Правильный выбор:**
- **Статический сайт** (без комментариев) → GitHub Pages ✅
- **Сайт с формой и БД** → Обычный хостинг с PHP ✅

**Рекомендация:** Для вашего проекта с комментариями используйте **бесплатный хостинг InfinityFree** - он поддерживает PHP и MySQL, и настройка очень простая!
