
# A.S.K.I.V.G Studio - Сайт-портфолио

## 📋 Описание проекта
Сайт-портфолио веб-студии A.S.K.I.V.G. Включает портфолио проектов, 
систему комментариев с модерацией, контактную форму, 3D визуализацию технологий.

## 🛠 Технологии
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: PHP 7.4+, MySQL
- **Библиотеки**: Swiper.js, AOS, CryptoJS
- **Сервер**: Apache + MySQL
