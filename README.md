
# A.S.K.I.V.G Studio - Сайт-портфолио
https://askivg.ru

## 📋 Описание проекта
Сайт-портфолио веб-студии A.S.K.I.V.G. Включает портфолио проектов, 
систему комментариев с модерацией, контактную форму, 3D визуализацию технологий.

## 🛠 Технологии
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: PHP 7.4+, MySQL
- **Библиотеки**: Swiper.js, AOS, CryptoJS
- **Сервер**: Apache + MySQL

## 📁 Структура проекта
askivg/
├── config/ # Конфигурационные файлы
├── css/ # Стили (модульная структура)
├── js/ # JavaScript модули
├── php/ # PHP обработчики
├── logs/ # Логи (создаются автоматически)
├── proekty/ # Демо проектов
├── .env # Переменные окружения (не в git)
├── index.html # Главная страница
└── moderation.php # Панель модерации
